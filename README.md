## Recent Projects

### Relation-Based Knowledge Distillation for MobileVLM

Implemented text–image relation matching between a frozen MobileVLM V2 7B teacher and a 3B student, trained with LoRA and evaluated on GQA.

The repository includes the notebook, Python scripts, experiment configuration and measured dev/testdev results.

[Explore the project](https://github.com/Muzna-farooq/mobilevlm-relation-kd)

### Frequent Closed Itemset Mining with LCM in Java

An educational implementation of LCM using prefix-preserving closure extension and occurrence delivery.

Validated with 657 exhaustive comparisons across 100 random databases. Tested 51 dataset/support combinations across 14 datasets: 46 completed and 5 reached the configured time limit.

The repository includes Java code, correctness tests, measured benchmark results, a performance chart and a report.

[Explore the project](https://github.com/Muzna-farooq/lcm-java-itemset-mining)
